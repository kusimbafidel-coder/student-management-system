Welcome to the Student Management System

This project helps a school manage student details, courses, attendance, and exam results. Add, view, or delete these records using the pages in the navigation.

View student records

About this project

The system has four related parts: student details, courses, attendance, and exam results. Attendance and exam records are linked to students, and exam results are also linked to courses.

This project uses HTML and CSS for the pages, PHP for the backend, and the MySQL database included with XAMPP to store records. The other pages show a student's name and course name by looking up their IDs in the related tables.

Start Apache and MySQL in XAMPP, then open this site at http://localhost/your-folder-name/. Do not open index.html directly; PHP pages will download instead of running.

What you can explore

  • Keep a list of students and courses.
  • Record whether a student was present or absent on a date.
  • Save a student's exam grade and marks for a course.
